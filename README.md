# MainsCraft VLSI Internship - Task 1

##  Project Overview
This repository contains the simulation files and documentation for **Task 1: Introduction to VLSI Design Flow and Basic Digital Logic Implementation**. 

The purpose of this assignment is to establish fundamental concepts of IC design stages and verify elementary digital components before advancing to hardware description language (HDL) modeling.

---

##  Learning Objectives
* Learn the complete end-to-end industry **VLSI Design Flow**.
* Understand basic logic levels, CMOS, and digital principles.
* Implement and simulate basic logic gates using visual schematic tools.
* Build and verify a combinational **Half Adder** circuit.

---

## 🛠️ Tools Used
* **Primary Schematic Simulator:** `Logisim` (Recommended offline digital logic simulator)
* *Alternative environments:* CircuitVerse, Falstad, or Digital (by H. Neemann)
